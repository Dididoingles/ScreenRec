# ScreenRec
ScreenRec - Gravador de Guia Minimalista
Um gravador de tela web ultra-minimalista focado em gravar guias específicas do navegador capturando exclusivamente o áudio do seu microfone (isolando sons do sistema ou da própria aba). Ideal para professores, criadores de conteúdo e tutoriais rápidos.

 Recursos
Foco na Captura de Guia: Interface otimizada para você selecionar exatamente a aba que deseja gravar.

Áudio Isolado: Captura apenas a voz do microfone selecionado (ex: JBL Quantum, microfone embutido, etc.), ignorando ruídos internos do computador.

Design Responsivo: Layout inteligente adaptado para computadores (lado a lado) e dispositivos móveis (flex vertical).

Sem Instalação: Roda diretamente no navegador, sem extensões ou programas pesados.

Privacidade: Todo o processamento e gravação acontecem localmente no seu navegador. Nenhum dado é enviado para servidores externos.

Como Executar o Projeto
Como o projeto foi desenvolvido puramente em HTML, CSS e JavaScript, você não precisa instalar nenhuma dependência.

Baixe o arquivo index.html (ou clone este repositório).

Dê um duplo clique no arquivo index.html para abri-lo em qualquer navegador moderno (Google Chrome, Microsoft Edge, Brave, Opera).

Conceda a permissão de microfone quando o navegador solicitar.

Como Usar
Selecione o Microfone: No painel da direita, escolha qual dispositivo de áudio deseja usar.

Inicie a Captura: Clique no botão "Selecionar Guia e Gravar".

Escolha a Aba: Na janela nativa do navegador, escolha a guia que você quer transmitir e clique em compartilhar.

Grave: O preview da guia aparecerá à esquerda e o status mudará para Gravando.

Finalize: Quando terminar, clique em "Parar Gravação" (ou no botão nativo do navegador).

Salve ou Descarte: Escolha se deseja fazer o download do arquivo de vídeo (.webm) ou descartá-lo para iniciar uma nova captura.

Tecnologias Utilizadas
HTML5 & CSS3 (Variáveis nativas e Flexbox/Grid)

JavaScript Vanilla (MediaRecorder API & MediaDevices API)

Lucide Icons (Pacote de ícones minimalistas via CDN)

Google Fonts (Fonte Poppins)
